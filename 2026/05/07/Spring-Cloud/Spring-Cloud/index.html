Spring Cloud

1. 集群与分布式

  • 集群：将一个完整的系统部署到多个服务器上，每个服务器称为一个节点，多个节点组成一个集群，每个节点都可以独立运行，但是可以协同工作，实现高可用。
  • 分布式：将一个应用分为多个服务，每个服务部署到多个节点上，每个节点负责处理一部分请求，实现负载均衡和高可用。

集群与分布式的区别与联系

  • 从概念上：集群是多个机器做同一个事，分布式是多个机器做不同事。
  • 从功能上：集群每个节点是相同的，当一个故障时系统还是可以正常对外服务，分布式每个节点不同，当一个故障时会导致系统无法提供服务
  • 从联系上：实际上集群与分布式是共同存在的，分布式的节点上可以使用着集群，所以说是叫分布式架构。

2.什么是spring-cloud

spring-cloud是一个基于spring框架的分布式应用框架，它提供了一组工具，帮助开发者快速构建分布式应用。

3. spring-cloud的组件

服务发现/注册

在服务发现/注册中，有三种角色：

  • 服务提供者（Server）：用于提供服务给其他节点
  • 服务消费者（Clinet）：去调用其他节点提供的接口
  • 服务注册中心（Registry）：用于注册服务提供者和服务消费者，以及发现服务提供者
    服务注册：在Server启动时，在Registry中注册自身，并隔段时间发送心跳包来确保自身在线。
    服务发现：在Client启动时，在Registry中查询服务提供者列表，根据服务名称调用服务提供者提供的接口。
