Talk 项目介绍

1. 项目概述

Talk 是一个面向私聊场景的全栈社交聊天项目。项目提供用户注册与登录、资料维护、头像上传、好友申请与管理、私聊会话和基于 STOMP 的实时消息通信能力。

后端以 Spring Boot 为核心，前端使用 React 单页应用实现。用户完成登录后，可管理好友、查看好友资料、发起私聊并查询聊天历史。

2. 核心功能

用户与认证

  • 用户注册、登录和 Token 登录态校验。
  • 用户可修改账户名、头像和密码。
  • 修改密码后立即撤销旧 Token，用户必须使用新密码重新登录。
  • 头像保存为服务器本地绝对路径，访问头像时由后端读取并返回图片流。

好友系统

  • 查询好友列表和好友申请列表。
  • 按用户 ID 搜索并发送好友申请。
  • 同意或拒绝好友申请。
  • 删除好友和拉黑好友。
  • 好友关系状态包括：待确认、好友、拒绝、删除和拉黑。

私聊与消息

  • 基于 STOMP 协议的 WebSocket 私聊连接，连接地址为 /talk。
  • 客户端通过 /app/chat/init 创建或复用两人私聊会话。
  • 客户端订阅 /user/queue/chat 接收实时消息，订阅 /user/queue/chat/past 接收历史消息。
  • 同一对用户重复初始化时复用已有会话，不重复创建会话记录。
  • 消息先写入内存缓冲；当会话双方均离线后批量写入 MySQL。
  • 接收方在发送方仍在线时进入聊天，也能从历史查询中获取尚未落库的内存缓冲消息。

前端界面

  • 默认进入登录页，未登录访问受保护页面会跳转到登录页。
  • 提供注册、主页、资料修改、添加好友、好友申请、好友详情和聊天页面。
  • 主页展示当前用户资料和好友列表，并支持删除与拉黑操作。
  • 聊天页面按左右气泡展示双方消息，支持加载历史消息和实时收发。
  • 使用暖色纸本风格的响应式界面，适配桌面端和移动端。

3. 技术栈

层级 技术
后端框架 Spring Boot 3.5.5
Java JDK 17 兼容，当前开发环境使用 JDK 21
构建工具 Maven 3.8.1（Maven Wrapper）
ORM MyBatis-Plus 3.5.5
数据库 MySQL
实时通信 Spring WebSocket + STOMP
前端 React + TypeScript + Vite
前端部署 Nginx，默认对外端口 80
图标 Lucide React

7. 数据与安全说明

  • 登录态目前由服务端内存中的 Token 映射维护，服务重启后需要重新登录。
  • 当前密码存储沿用现有明文方案，仅适合课程设计或本地开发环境；正式部署应改用 BCrypt 等不可逆哈希算法。
  • 聊天消息的内存缓冲在应用重启前未落库时会丢失；生产环境建议使用消息队列、Redis 或即时持久化机制。
  • WebSocket 握手携带用户 ID 用于建立 STOMP 用户路由；正式环境应结合 Token 校验、HTTPS/WSS 和更严格的握手鉴权。
