聊天项目详解
Talk 项目介绍1. 项目概述Talk 是一个面向私聊场景的全栈社交聊天项目。项目提供用户注册与登录、资料维护、头像上传、好友申请与管理、私聊会话和基于 STOMP 的实时消息通信能力。 后端以 Spring Boot 为核心，前端使用 React 单页应用实现。用户完成登录后，可管理好友、查看好友资料、发起私聊并查询聊天历史。 2. 核心功能用户与认证 用户注册、登录和 Token 登录态校验。 用户可修改账户名、头像和密码。 修改密码后立即撤销旧 Token，用户必须使用新密码重新登录。 头像保存为服务器本地绝对路径，访问头像时由后端读取并返回图片流。 好友系统 查询好友列表和好友申请列表。 按用户 ID 搜索并发送好友申请。 同意或拒绝好友申请。 删除好友和拉黑好友。 好友关系状态包括：待确认、好友、拒绝、删除和拉黑。 私聊与消息 基于 STOMP 协议的 WebSocket 私聊连接，连接地址为 /talk。 客户端通过 /app/chat/init 创建或复用两人私聊会话。 客户端订阅 /user/queue/chat 接收实时消息，订阅...
